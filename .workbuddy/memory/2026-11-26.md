- 用户实测脚本：生成 .env 后卡住无输出、无容器。定位根因：`set -euo pipefail` 下 `check_port` 写成 `ss ... | grep -q ... && log_warn`，端口未被占用时 grep 返回 1，整个 check_port 函数返回 1 触发 set -e 静默退出，恰好卡在 prepare_env 之后。用 `bash -c` 复现确认（未修复前 EXIT=1 且无后续输出）。
- 修复：`check_port` 改为 `if ...; then log_warn; fi` 显式条件 + 末尾 `return 0`，避免 grep 非零状态触发 set -e。修复后模拟验证 EXIT=0 且后续流程可执行，`bash -n` 通过。
- 经验：set -e 脚本中 `cmd && handler` 形式的检测语句，当 cmd 未命中返回非零时会导致整个函数/脚本静默退出，务必用 if 包裹或 `|| true`。
